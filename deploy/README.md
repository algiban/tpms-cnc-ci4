# TPMS production deployment templates

Semua file di folder ini adalah baseline yang harus disesuaikan dengan distro, versi PHP, path project, RAM server, domain/IP dan kebijakan perusahaan.

Urutan baca: `../PHASE7_PRODUCTION_SERVER_TUNING.md` dari root project.

Jangan menyalin `.env.production.example` tanpa mengganti seluruh nilai `CHANGE_ME`.
